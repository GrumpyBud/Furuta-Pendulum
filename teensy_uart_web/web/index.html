LOW-TORQUE BALANCE TRIAL

Hold to test

Manually place the pendulum nearly upright and motionless. Press and continuously hold the button. Releasing it, leaving the catch region, losing USB keep-alives, opening the safety loop, or reaching 8 seconds requests idle and faults.

Complete every setup check.

Tuning rule

Change only one value by 5–10% between trials and save the telemetry log. Automatic gain searching is intentionally not provided: moving hardware cannot safely identify an unknown Furuta pendulum without measured mechanics, experiment design, and expert review.
