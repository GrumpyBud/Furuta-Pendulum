Coupling sign check

Keep motor power disconnected. First choose an arm direction and verify its dashboard angle becomes positive. Then hold the pendulum near upright and move the arm gently but briskly in that positive direction; as the pendulum top initially lags, its dashboard angle must also move positive. If not, change only kPendulumDirection, rebuild, and repeat. After this is repeatable, set kControlDirectionVerified = true. Never compensate by flipping gain signs.

LOW-TORQUE BALANCE TRIAL

Hold upright, then hold Space

Manually place the pendulum nearly upright and motionless, then press and hold Space. The trial starts automatically—no mouse click is required. Releasing Space, changing browser tabs, losing keep-alives, leaving the catch region, or reaching 20 seconds stops motor output.

Complete every setup check.

Trial rule

Start with Hardware tuned. Save each telemetry log and release Space immediately if motion grows. Exact individual gains are advanced controls; prefer the reviewed profiles. Blind automatic searching remains disabled because collisions and saturation produce unsafe, misleading “learning.”
